Prečo

  • 2% SR skutočne chránené
  • úrady udeľujú výnimky na zásahy

Demo

michalfapso.github.io/vlk_uradne_tabule/

Flow

  • Scraping [minv.sk, minzp.sk]
  • PDF → TXT
  • TXT → znenia odkazovaných § ← [slov-lex.sk]
  • TXT → LLM → JSON
  • JSON → GIS polygony ← [kataster OGC, OSM, sopsr.sk]
  • → JSON
  • Astro.js → static web → GH Pages

Použité technológie

  • Python + LiteLLM
  • Astro
  • GitHub Actions
  • GitHub Pages

Čo bolo do projektu dorobené tento víkend

  • LLM prompt feedback
  • normalizácia geonázvov pre GIS
  • frontend UI
  • ručná analýza analýzy :D

Roadmap
